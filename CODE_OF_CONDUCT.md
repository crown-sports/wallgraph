# Community conduct

Participants in this project's issues, pull requests, reviews, and other project spaces are expected to treat each other respectfully. Welcome people with different backgrounds and experience levels, discuss technical claims with evidence, and accept corrections without personal attacks.

Harassment, discriminatory language, threats, impersonation, spam, and publishing another person's private information are unacceptable. Do not upload credentials, private floor plans, datasets, or model files to project discussions.

For disruptive public content, use GitHub's **Report content** control and alert the repository maintainer without repeating sensitive material. If a report needs private details, request a private contact route without posting those details. Security vulnerabilities use the separate process in [SECURITY.md](SECURITY.md).

Maintainers may edit or remove content, close or lock conversations, and restrict participation to protect the community. Responses should consider severity, context, and repeated behavior. A participant may request reconsideration with a respectful factual summary. These rules apply to maintainers as well as contributors.
